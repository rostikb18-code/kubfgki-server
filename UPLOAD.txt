ROSTIKAI v31.1.3 — GITHUB UPLOAD V6

В этой папке 5 частей проекта. Каждая ZIP-часть меньше 25 MB.

1) Загрузи PART-01 ... PART-05 в корень GitHub-репозитория.
2) В корень репозитория положи build.yml из этой папки как:
   .github/workflows/build.yml
3) Не переименовывай PART-файлы.
4) После загрузки открой GitHub Actions и запусти workflow.
5) После успешной сборки APK будет в Artifacts.

SHA256.txt содержит контрольные SHA256 всех пяти частей.
